# 分镜台

输入一段剧本，输出结构化分镜表。可以改、可以导出。

## 跑起来

```bash
node server.mjs
# 打开 http://127.0.0.1:7788
```

Windows 上双击 `start.cmd` 也一样。没有 node_modules，不用装依赖。

用之前先配 Key：复制 `.env.example` 为 `.env`，填一个：

```
DEEPSEEK_API_KEY=sk-xxxx
```

不配 Key 也能打开，会走内置示例数据，用来演示兜底。

## 它做了什么

分两步调模型，不是一步：

1. **建设定卡** —— 人物、场景、道具。人物卡里有外观锚点、禁用特征、音色档案。
2. **带着卡拆镜头** —— 模型只能在设定卡的约束内拆，不能自己编角色。

拿到结果之后，前端还要过一遍规则引擎：

- 台词按 4.5 字/秒算，念不完的镜头拉长；超长超短按景别区间收敛
- 情绪高点 + 特写 + 固定机位，提示改推镜
- 拼首帧提示词时，把人物外观锚点和服装原样塞进去，不让模型改写
- 跑一致性检查：禁用词命中、角色挂了却没写进画面、道具登记了没出现、连续三镜同景别、台词角色没登记、服装或音色没设定

## 三处可以接管的地方

**生成前 · 导演意见**
剧本框下面有一个折叠的输入框，写"单镜不超过 4 秒""整体冷色调"这类要求，会作为最高优先级塞进提示词（但不能违反一致性规则）。

**生成后 · 按意见重做**
结果出来不满意，在左下写一句"最后一镜改成大特写，压到 2 秒"，点重做。只改意见涉及的部分，其它镜头保持不动。

**右侧 · 统一面板**
逐条列出每个角色和道具被哪些镜头用到：外观、几套服装分别用在哪几镜、音色、覆盖镜头数。音色可以直接改，改完表格里所有引用该角色的镜头同步变化；服装可以选中镜头后整套切换；道具可以选中镜头后一键挂上去。

一个角色可以有多套服装（换装），每个镜头都标明穿的是哪套，首帧提示词据此拼装。剧本里写"换了礼服"，模型就会给两套，场次之间自动切换。

输出字段：镜头号（ep01s01）、画面描述、中英双语台词、运镜方式/景别、人物/场景/道具（中英双名）、备注（音效 / 首帧承接 / 表情）、建议时长。表格 7 列，照分镜本的习惯排。

**设定卡能出参考图**：人物、每套服装、场景、道具各一张，用图片模型生成，存在服务端，同一句提示词不重复花钱。点卡片进二级页面可以改提示词、写「建议修改」（先让文本模型改写成新提示词，再出图）。

**分集管理**：左上角切换 / 新建集，每集独立存剧本和分镜，切回来还在。镜号按 `ep01s01` 连续编号。

导出 CSV、Excel、JSON、**Word（真 .docx，自己拼 OOXML 打的包）**，或者直接打印成分镜本。

## 为什么这么设计

分镜表不是给人看的文档，是下游图生视频和 TTS 的输入。所以每一列都要能对上：

| 字段 | 谁在用 |
|---|---|
| 景别 / 机位 / 构图 / 运镜 / 时长 | 图生视频 |
| 首帧提示词 | 文生图 |
| 台词 + 音色档案 | TTS |
| 角色 / 场景 / 道具 id | 一致性校验 |

一致性靠两件事：一是设定卡里的锚点在拼提示词时原样保留；二是生成后跑冲突检测，把矛盾标出来让人改。

## 目录

```
server.mjs            Node 服务：静态托管 + 调模型 + 出图 + JSON 修复重试
prompts.mjs           两段式提示词
public/
  index.html          三栏界面 + 二级详情页
  app.js              状态与渲染
  rules.js            规则引擎（纯函数）
  docx.js             读 .docx（上传剧本用）
  export-docx.js      写 .docx（自己拼 OOXML + zip，不依赖库）
  styles.css          样式
  samples.js          内置示例 + 离线兜底数据
test/rules.test.mjs   规则引擎单测
```

node test/rules.test.mjs

## 换模型

分镜和出图都走 OpenAI 兼容接口，改 `.env` 就行：

```
# 文本（分镜、改写提示词）
LLM_BASE_URL=https://api.openai-next.com/v1
LLM_API_KEY=sk-xxxx
LLM_MODEL=gpt-5.6-sol

# 出图
IMAGE_MODEL=gpt-image-2
IMAGE_QUALITY=medium
```

填了 `LLM_API_KEY` 就走这套；留空则自动退回 DeepSeek / 智谱，界面照常能看。
出图约 60–100 秒一张，参考图存 `public/thumbs/`（已在 gitignore）。

## 还没做的

- 视频：出图只有关键帧，没接图生视频
- 音色：只做到匹配和确认，没接 TTS 出声
- 长剧本：建议 6000 字以内，跨段需要把设定卡传下去
- 泰语台词是模型翻译的，没有术语表校验
- 表格里没有缩略图，图在卡片视图和二级页面里看
